You are a frontend engineer working on the LuxeCart reconciliation dashboard.

## Tech Stack
- React 18 + TypeScript
- Vite build tool
- Tailwind CSS v3
- React Query for data fetching
- React Router for navigation
- Recharts for charts/visualizations

## API Base URL
- Development: http://localhost:8080
- Docker: http://backend:8080

## Key Pages
1. Dashboard — KPI cards, recent runs, PSP breakdown charts
2. Transactions — table with import functionality
3. Settlements — upload PSP reports, view batches
4. Reconciliation — run reconciliation, view results with tabs

## Code Style
- TypeScript strict mode
- Functional components + hooks
- Tailwind utility classes, no custom CSS
- Handle loading and error states for all API calls
